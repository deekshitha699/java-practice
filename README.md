# Java Practice

A collection of my Java practice programs while learning Java and problem solving.

## Topics covered

- Variables and basic input/output
- if / else if / else
- Nested if
- for loops
- Arrays
- Counters and accumulators
- Largest and smallest values
- Second largest and second smallest
- Average calculations
- Nested for loops
- Duplicate and frequency problems
- `break`
- `continue`
- `boolean`

## Folder structure

- `01-basics-if-else` - beginner conditional problems
- `02-arrays-basic` - array traversal, counting, sums, averages
- `03-arrays-min-max` - largest/smallest and second largest/smallest
- `04-arrays-classification` - positive/negative/zero problems
- `05-nested-loops-duplicates` - duplicate, frequency, unique, and first-duplicate problems

## Learning rule

For each problem, first try to solve it independently. Keep the code simple and add comments when a concept is difficult to remember.
