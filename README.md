# Java Practice

A collection of my Java practice programs while learning Java and problem solving.

## Topics Covered

- Java basics
- If-else statements
- Arrays
- Array min and max problems
- Array classification
- Nested loops
- Duplicate elements
- Digit-based problems

## Practice Structure

### 01 - Basics If Else
Basic problems using if-else statements.

### 02 - Arrays Basic
Basic array problems and operations.

### 03 - Arrays Min Max
Problems related to minimum and maximum values in arrays.

### 04 - Arrays Classification
Problems involving classification of array elements.

### 05 - Nested Loops and Duplicates
Problems using nested loops and duplicate checking.

### 06 - Digit Problems
Problems involving individual digits of a number, including:

- Count digits
- Sum of digits
- Largest digit
- Smallest digit
- Reverse number
- Palindrome
- Even and odd digit count
- Digit frequency
- Most frequent digit
- Least frequent digit
- Second largest digit
- Second smallest digit
- Second most frequent digit
- First and last digit
